# ME.Coach — install on Hostinger

## Install
1. hPanel → File Manager → `public_html`. Upload `me-coach.zip` and **Extract**. You get `public_html/coach/`.
2. PHP 8 or later (hPanel → Advanced → PHP Configuration).
3. Open **https://miladebrahimi.me/coach/**. The first account created is the **owner** (you). Everyone after you gets a 7-day free trial.
4. Check that `https://miladebrahimi.me/coach/data/users.json` answers 403 or 404 (private).

## Your account (owner)
- Start free → your name → **Skip — I will import my own data** → email and password.
- Settings → Import JSON: first your old MILAD 2031 backup, then `me-coach-milad-plan-2026-11-16.json` (it replaces areas, goals, milestones, courses, habits and cycles; the old ones go to Trash).
- Settings → **Members**: see every account; **+30 d / +1 y** activates a subscriber after they pay you, **Stop** ends access.

## Launch settings (7.1)
- Members → **Payments and sign-in**: manual payment text (bank or Thawani link), WhatsApp, contact email.
- Optional automatic billing: Lemon Squeezy checkout link per plan + webhook URL shown there + signing secret.
- Optional Google sign-in: create a Web OAuth client ID in Google Cloud (origin `https://miladebrahimi.me`) and paste it there.
- Public pages (`index.html`, `features.html`, `pricing.html`, `book.html`, `faq.html`, `privacy.html`, `terms.html`) are generated by `platform/tools/build_coach_site.py`. Prices live there and in `PLANS` in `api.php`.
- Submit `https://miladebrahimi.me/coach/sitemap.xml` in Google Search Console.

## Version 10

- AI assistant (Claude): Settings → AI assistant → Add key. Create the key at console.anthropic.com (API keys). It stays on your server; set a daily limit to control cost. Without a key every AI button shows a clear message and the rest of the app works.
- Google Calendar: Settings → Google Calendar → paste the “Secret address in iCal format”. Events are imported every 6 hours (read-only).
- 40-day report: Life → ⋯ → 40-day report (with an AI review and Save as PDF).

## Version 9

- Upload the zip over the existing `coach` folder and extract. Do not delete the folder: `data/` keeps every account.
- Book method end to end: the full 80-question Balance Wheel Test, the 5-step Goal to Micro-Action wizard, improvement actions in Morning and Night Balance, and the daily assessment score (out of 10).
- Owner courses: on first sign-in the owner account keeps only the 14 Coursera courses from the plan; other courses move to Trash (restorable).
- Job Autopilot (owner): More → Job search → Autopilot.
  1. In Hostinger → Emails, create a mailbox such as `jobs@miladebrahimi.me`, then enter it under Autopilot → “Add keys” → “Send applications from”.
  2. Optional free search keys: Adzuna (developer.adzuna.com: UK, New Zealand), Reed (reed.co.uk/developers: UK), Jooble (jooble.org/api/about: Ireland and more). Remotive (remote jobs) works without a key.
  3. Upload your CV (PDF). The latest upload is attached to every approved email.
  4. The existing 15-minute cron job also runs the daily search when Autopilot is on.
  Nothing is sent without your approval tick; max 25 emails a day.

## Version 8
- Emi, the 3D guide, uses `assets/vendor/three.min.js` (three.js, MIT licence) and `assets/emi.js`. Users can hide Emi in More → Emi guide.
- Tests (`assets/tests-data.js`) and the Career explorer (`assets/career-data.js`) load only when opened. Tests need a paid plan (owner always has access).

## Updating later
- Extract the new zip over the `coach` folder. **Never delete the folder**: `coach/data/` holds every user's data.

## Home-screen widget (7.0)
- Today → **Edit widgets** → **Set up home-screen widget**. iPhone/iPad: free app *Scriptable* + the copied script. Mac/Windows: open the desktop widget link (Safari → File → Add to Dock).

## Reminders (optional)
- Each user turns them on in Settings → Notifications (installed app, iOS 16.4+).
- One cron job for everyone: hPanel → Advanced → Cron Jobs → every 15 minutes, with the command shown in Settings → Notifications.

## نصب (فارسی)
۱. فایل `me-coach.zip` را در `public_html` آپلود و Extract کنید تا پوشه `public_html/coach/` ساخته شود.
۲. آدرس **miladebrahimi.me/coach** را باز کنید. اولین حساب، حساب مالک (شما) است و بقیه ۷ روز رایگان دارند.
۳. در صفحه اول Start free → نام → «Skip — I will import my own data» → ایمیل و رمز.
۴. Settings → Import JSON: اول بک‌آپ قدیمی MILAD 2031، بعد فایل برنامه جدید.
۵. برای به‌روزرسانی، zip جدید را روی همان پوشه `coach` Extract کنید (Overwrite) و هرگز پوشه را پاک نکنید. هر دو فایل `api.php` و `assets` باید با هم آپدیت شوند.
